\# GTC-HD Research



This directory contains source-code investigations, comparative architecture studies, experiment reports, and other research supporting GTC-HD technical decisions.



Research findings are evidence, not automatically accepted architecture.

[Project State](../PROJECT_STATE.md) records current scoped results and the next review decision. [Product Direction](../PRODUCT_DIRECTION.md) holds already approved intentions. The October 6 reconciliation prepared [Knowledge Base v2.0](../knowledge/KNOWLEDGE_BASE.md) and [Custom GPT Instructions v2.0](../knowledge/CUSTOM_GPT_INSTRUCTIONS.md) as proposed replacements pending review, and a [DRAFT offline replay/preview contract](../specs/OFFLINE_REPLAY_PREVIEW.md); implementation is not authorized. The [publication map](BSNES_EXPERIMENT_PUBLICATION_MAP.md) distinguishes the dated public-source snapshot from later corrected local integrations.

[PixelRamp related work and GTC-HD product/roadmap implications](PIXELRAMP_RELATED_WORK.md) records public claims, explicit product-direction approval, unresolved technical choices and a proposed later vertical slice.

[Post-EXP-004 comparative design audit](RELATED_WORK_SURVEY.md) maps focused external mechanisms to current capture evidence and proposes a bounded native-sample replay with a frozen source-selection and enhancement preview.



Important project decisions should be reflected in canonical project state and, when appropriate, formal Architecture Decision Records.
