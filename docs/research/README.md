\# GTC-HD Research



This directory contains source-code investigations, comparative architecture studies, experiment reports, and other research supporting GTC-HD technical decisions.



Research findings are evidence, not automatically accepted architecture.

[PixelRamp related work and GTC-HD product/roadmap implications](PIXELRAMP_RELATED_WORK.md) records public claims, explicit product-direction approval, unresolved technical choices and a proposed later vertical slice.



Important project decisions should be reflected in canonical project state and, when appropriate, formal Architecture Decision Records.
